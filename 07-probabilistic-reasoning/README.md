# Probabilistic Reasoning

## Overview

Probabilistic Reasoning is a fundamental area of Artificial Intelligence that allows systems to make decisions and infer hidden information under uncertainty.

Unlike deterministic algorithms, where inputs always produce fixed outputs, real-world AI systems often operate with incomplete, noisy, or uncertain information.

Probabilistic models provide a mathematical framework for representing uncertainty and updating beliefs when new evidence becomes available.

This section covers:

- Probability fundamentals
- Bayesian reasoning
- Bayesian Networks
- Hidden Markov Models
- Monte Carlo methods
- Rejection Sampling
- Gibbs Sampling

All major concepts were implemented from scratch using Python to understand the underlying algorithms.

# 1. Probability Fundamentals

Probability provides the mathematical foundation for reasoning under uncertainty.

Important concepts covered:

- Random variables
- Events and outcomes
- Conditional probability
- Probability distributions


## Conditional Probability

Conditional probability describes the probability of an event given that another event has already occurred.

\[
P(A|B)=\frac{P(A \cap B)}{P(B)}
\]


Example:

The probability of rain given that the grass is wet:

\[
P(Rain|WetGrass)
\]


This concept is the foundation of Bayesian inference.

---

# 2. Bayesian Reasoning

Bayesian reasoning allows AI systems to update their beliefs when new evidence becomes available.

The core equation is Bayes' theorem:

\[
P(A|B)=
\frac{P(B|A)P(A)}
{P(B)}
\]


Where:

| Term | Meaning |
|-|-|
| Prior | Initial belief |
| Likelihood | Probability of observing evidence |
| Evidence | Probability of observed data |
| Posterior | Updated belief after evidence |


## Implementation

A Bayesian calculator was implemented from scratch to demonstrate belief updates.

Example:

Medical diagnosis scenario:

Initial disease probability:
P(Disease)=1%


After receiving a positive test result:

P(Disease | Positive Test)

was calculated using Bayes theorem.


The experiment demonstrated that evidence updates beliefs but does not completely replace prior knowledge.

# 3. Bayesian Networks

## Concept

A Bayesian Network is a probabilistic graphical model that represents dependencies between random variables.

It consists of:

- Nodes: Random variables
- Edges: Conditional dependencies
- CPT: Conditional Probability Tables


Example:


Cloudy
   |
   ↓
 Rain
   |
   ↓
Wet Grass


Instead of representing a large joint probability table, Bayesian Networks factorize the probability distribution:

\[
P(C,R,W)
=
P(C)
P(R|C)
P(W|R)
\]

# 4. Hidden Markov Models (HMM)

## Concept

Hidden Markov Models are probabilistic models for sequential data.

They are used when the real state of a system is hidden, but observations are available.


HMM contains:

## Hidden States

Variables that cannot be directly observed.

Example:


Sunny
Rainy


## Observations

Observable events:


Walk
Shop
Clean


The model:


Hidden State
      |
      ↓
Observation


---

# HMM Implementation

A Hidden Markov Model was implemented from scratch with:

- Initial probabilities
- Transition probabilities
- Emission probabilities
- Forward algorithm
- Viterbi algorithm


Example model:


Weather State
Sunny
Rainy
Activities
Walk
Shop
Clean


---

# Forward Algorithm

The Forward algorithm calculates:

\[
P(Observation Sequence)
\]


It answers:

> How likely is this sequence generated by the model?


Example:


Walk → Shop → Clean


---

# Viterbi Algorithm

The Viterbi algorithm finds the most probable hidden state sequence.


Example:

Observed:


Walk → Shop → Clean


Predicted:


Sunny → Rainy → Rainy


This demonstrates how HMMs infer hidden information from observable events.

# 5. Sampling Methods

When exact probability calculations become computationally expensive, sampling methods provide approximate solutions.

The implemented methods:

- Monte Carlo Sampling
- Rejection Sampling
- Gibbs Sampling


---

# Monte Carlo Sampling

Monte Carlo estimates probabilities using random samples.


Example:

Estimating π:

\[
\pi \approx
4 \times
\frac{Inside\ Points}
{Total\ Points}
\]


Experiment:

The number of generated samples was increased.

Observation:


More samples → Better approximation


The visualization showed convergence toward the real value of π.

---

# Rejection Sampling

Rejection Sampling generates samples from difficult distributions by using an easier proposal distribution.


Process:


Generate Sample
        ↓
Acceptance Test
        ↓
Accept / Reject


The experiment sampled from a target distribution using a simpler proposal distribution.

The resulting histogram demonstrated that accepted samples approximate the target distribution.

---

# Gibbs Sampling

Gibbs Sampling is a Markov Chain Monte Carlo method used for sampling from complex probability distributions.


Instead of rejecting samples, Gibbs Sampling updates variables iteratively:


Current State
  ↓

Update Variable
  ↓

New State


A binary-variable Gibbs sampler was implemented.

The generated samples were analyzed by observing the frequency of possible states.
